# Troubleshooting

- Approval required: import independently verified evidence and explicitly
  confirm it in Settings. Never bypass the compatibility gate.
- Executable changed: the approved path, hash or version no longer matches.
  Re-verify the official upgrade and create new evidence.
- Authentication required: sign in through official Codex, then refresh
  manually. The monitor does not inspect credentials.
- Stale or unavailable data: cached values remain visible while the status
  identifies the failure; retry with manual refresh after recovery.
- Protocol failure: review the sanitized diagnostic category and exact version
  compatibility. Do not publish credentials or raw account responses.

The hardened build has no automatic updater, service, or supplied
installer/uninstaller. See [installation](installation.md).
