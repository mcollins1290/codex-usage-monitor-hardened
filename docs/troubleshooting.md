# Development troubleshooting

This branch is not an approved installation or release. Live quota polling is intentionally disabled until runtime acceptance.

- Approval required: inspect the compatibility status in Settings. Do not bypass the launch freeze.
- Executable changed: the approved path, hash or version no longer matches. New evidence and explicit approval are required.
- Authentication required: after runtime acceptance, sign in through official Codex and refresh manually. The monitor does not inspect credentials.
- Protocol failure: review sanitized diagnostic categories and exact version compatibility. Do not publish credentials, local paths or raw account responses.

The hardened build has no automatic updater or supplied installer/uninstaller. Do not use upstream installation instructions. See [development status](DEVELOPMENT-STATUS.md).
