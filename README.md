# Codex Usage Monitor Hardened (development only)

This is an unfinished security-focused fork of [Codex Usage Monitor](https://github.com/upstream-ray/codex-usage-monitor), distributed under the original MIT license. See LICENSE for attribution.

**Do not install or launch this development build for live use.** Authenticated app-server launch is blocked in code until startup verification is accepted. No release or installer is provided. The original application's installation instructions and binaries do not apply to this fork.

See [architecture](docs/hardened-architecture.md) and [implementation plan](docs/hardening-implementation-plan.md).
