# Codex Usage Hardened

本项目是仅支持 Codex 的 Windows 任务栏额度监控工具，目前处于安全开发阶段。尚未批准安装、发布或登录账户后的额度查询。

程序不会直接读取 OAuth 凭据，不使用直接 HTTP 额度查询，不支持其他服务、自动更新或 MCP 监听器。未来的额度查询将通过经过明确验证和批准的官方 Codex app-server 进行。

请参阅 [English README](README.md)、[开发状态](docs/DEVELOPMENT-STATUS.md) 和 [运行验证要求](docs/RUNTIME-ACCEPTANCE.md)。不要将上游发布的二进制文件视为本项目的安全版本。
